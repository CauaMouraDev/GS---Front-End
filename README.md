# ChuvAlerta

Site expositivo de um protótipo que mede a altura da água em ruas sujeitas a alagamentos e alerta a população local.

## Como abrir

Abra `index.html` no navegador. Não é necessário instalar dependências.

## O que o site apresenta

- O problema e a proposta do ChuvAlerta.
- As tecnologias: Arduino, Python, HTML, CSS e JavaScript.
- Os níveis de alerta: atenção a partir de 15 cm e perigo a partir de 30 cm.
- Um simulador demonstrativo e ilustrações do projeto.

> O simulador é ilustrativo: não recebe medições reais do sensor. Os limites e resultados não substituem alertas oficiais.
